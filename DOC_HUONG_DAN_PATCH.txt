SAO LƯU VÀ CẬP NHẬT TRÊN WINDOWS (PowerShell đang ở expense-tracker-main):
1. Dừng server Ctrl+C.
2. Sao lưu dữ liệu JSON nếu có:
   if (Test-Path .\data\db.json) { Copy-Item .\data\db.json .\data\db.backup-truoc-patch.json }
3. Tải file ZIP PATCH về thư mục Downloads.
4. Expand-Archive -Path "$env:USERPROFILE\Downloads\fintrack-patch-review-19-10-2026.zip" -DestinationPath (Get-Location).Path -Force
5. npm run lint
6. npm test
7. npm run build
8. npm run dev

Lưu ý: zip không đụng data/db.json hay .env; MongoDB cần sao lưu riêng bằng mongodump hoặc export từ Compass.
Những ca thử MongoDB thực tế và giao diện vẫn cần xác minh trên máy người dùng.
